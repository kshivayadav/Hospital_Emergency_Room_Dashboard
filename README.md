🏥 Hospital Emergency Room Dashboard (Excel)
📌 Project Overview

This project is an interactive Excel dashboard designed to analyze Hospital Emergency Room (ER) performance. It provides insights into patient volume, wait times, admission trends, demographics, consultation delays, and departmental referrals. 
The dashboard is built to help hospital administrators and staff make data-driven decisions to optimize operations and improve patient care.

📊 Key Features

Dynamic Filtering: Slice data by Month and Year to generate custom reports.

Performance Metrics:

Total Patients

Average Wait Time

Average Rating

Admission Status (Admitted vs. Not Admitted)

Visual Insights:

Patient Attend Status (On-time vs. Delay)

Patients by Gender Distribution

Patients by Age Group

Patients by Department Referral

Data Processing: Applied data cleaning, formulas, conditional formatting, and Pivot Tables for accurate reporting.

Insights Generated: Identified that 58% of patients faced consultation delays, supporting process improvement initiatives.

🛠️ Tools & Skills Used

Microsoft Excel

Pivot Tables & Pivot Charts

Slicers for interactive filtering

Conditional Formatting

Data Cleaning & Formulas

Dashboard Design & Visualization

🚀 Impact

Helped uncover consultation delays and patient flow inefficiencies.

Delivered visual KPIs for hospital administration to improve decision-making.

Demonstrated real-world application of Excel for healthcare analytics.

💡 Business Recommendations

Based on the analysis, the following actions are recommended to improve ER efficiency and patient experience:

Reduce Consultation Delays:

Allocate more doctors during peak hours to address the 58% delay rate.

Implement a triage system to prioritize critical cases quickly.

Optimize Staffing:

Patient inflow is higher in age groups 10–19 and 60–69; consider adding specialized staff (pediatric and geriatric care).

Ensure adequate orthopedics and general practice doctors, as they receive the highest referrals.

Improve Patient Satisfaction:

Average rating (5.09) suggests scope for improvement—reduce waiting times and enhance communication.

Provide regular feedback forms to track service quality.

Resource Allocation:

Since nearly 50% of patients are not admitted, consider expanding outpatient care facilities to improve throughput.

Leverage insights on gender and age distribution for targeted awareness and preventive care programs.
